# Git hooks

`mise run setup` で、このリポジトリの Git hooks を有効にします。
既存のチェックアウトでは、次のコマンドだけでも有効にできます。

```sh
mise run hooks:install
```

コミット前に `.githooks/pre-commit` が次を順番に実行します。

1. `mise run //:format` でoxfmtによる整形を上書きする
2. ステージ済みファイルに未ステージの変更がないか確認する
3. `mise run //:lint`

失敗するとコミットを中止します。整形・チェック対象は `shared/` を含む通常のタスクと同じ範囲です。
ステージした内容だけでなく、作業ツリー全体を整形・検査するため、未ステージの変更も対象です。
自動ステージは行いません。

整形後の内容をコミットに含めるため、ステージ済みファイルに未ステージの変更がある場合はコミットを中止します。
差分を確認して必要な内容をステージし直し、再コミットしてください。
ファイルの一部だけをステージしている場合も同様です。未ステージの変更を含むファイルがステージ対象外なら、この確認ではコミットを中止しません。
lint違反は修正後に `mise run lint` で確認してから再コミットしてください。

Gitを実行する環境のPATHに `mise` が必要です。GUIからコミットする場合も同様です。
設定はローカルの `core.hooksPath` に保存されるため、クローンごとにセットアップが必要です。
